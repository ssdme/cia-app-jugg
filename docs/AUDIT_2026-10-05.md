## Findings

### A1 â€” P1 â€” Effect toggles use incompatible keys

The UI initializes camelCase and snake_case variants. Gallery toggles update the snake_case entry, while Rust deserializes camelCase and ignores unknown fields. A targeted reproduction disabled `one_framers` while leaving `oneFramers` enabled. Advanced shakes and exposure flash have similar mismatches; CC Deep Dark and Anti-Flash use distinct OR-based handling.

Use one canonical field per option, an explicit gallery-to-IPC mapping, and tests proving disabled effects disappear from plans and frames. Relevant files: [App](../src/App.svelte), [plan contract](../src-tauri/src/plan.rs).

### A2 â€” P1 â€” Presets and FULL FX do not apply advertised values

The JavaScript default helper ignores style and FULL FX arguments. HARD/ON and SMOOTH/OFF produce identical overrides, which override Rust defaults. Changing style also retains numeric HARD parameters initially loaded by onMount.

Rust should supply a complete preset, including numeric parameters and enabled effects. Distinguish preset values from user overrides and reject stale asynchronous preset responses.

### A3 â€” P1 â€” Selecting a later source can seek beyond its end

Gallery timestamps are cumulative, but the renderer receives only selected paths. Selecting the third of three ten-second clips passes global [20,30] to a single-source decoder as `-ss 20 -t 10`. The actual generator reproduced this mapping. FFmpeg can return success with zero decoded bytes when seeking beyond the source.

Represent ranges as source-local `{ sourceId, start, duration }` and preserve the full source-path identity table. Test each source alone, discontinuous selection and mixed frame rates. See [sources](../src-tauri/src/sources.rs).

### A4 â€” P1 â€” Cancellation permits an overlapping restart

CANCEL immediately returns the UI to idle while the old worker may still read, write or wait for FFmpeg. A new render resets the shared cancellation flag. Jobs also share a PID-named raw cache, broad cleanup and non-atomic output-name checks.

Use per-job cancellation, job-filtered progress, a cancelling state until confirmed cleanup, render exclusion, dedicated temporary files and atomic output publication. Test cancellation and immediate restart in every phase.

### A5 â€” P1 â€” Blocking analysis can freeze the window

Beat, scene, metadata and thumbnail commands wait for native processes synchronously. Async render/transcription functions also perform blocking work directly. Move work to bounded workers, retain progress/cancellation, and cache analysis independently of UI state.

[Tauri async command documentation](https://v2.tauri.app/develop/calling-rust/#async-commands) explains the relevant scheduling behavior.

### A6 â€” P1 â€” Native process failures are insufficiently controlled

Encoder stderr is piped without being drained. Saturation can block FFmpeg and frame writes; this is a code-structure risk, not a reproduced deadlock in the short synthetic trials. [Rust pipe documentation](https://doc.rust-lang.org/std/process/struct.Stdio.html#method.piped).

A later decoder failure can also be missed because validation checks a cumulative decoded-byte count after an earlier successful source. Early returns do not consistently stop children and remove partial files.

Drain bounded stderr, check every source/process, centralize cleanup and publish only completed output. Test a corrupt second source, inaccessible output, noisy stderr and blocked pipes.

### A7 â€” P2 â€” Transition settings are serialized but ignored

Warp Bubble, Wave Warp and Slide Shake parameters are generated from controls, but rendering uses constants or fixed defaults. Consume typed parameters in preview and export, and compare frames at zero and active amplitudes.

### A8 â€” P2 â€” Plan and export validation are weak

H.264/WEBM and H.265/WEBM are independently selectable but rejected by the bundled FFmpeg; VP9/WEBM succeeds. Invalid dimensions, empty segments and non-finite values should fail before allocation or process launch. Scene arrays also ambiguously guess boundaries versus pairs.

Centralize plan validation, make scene format explicit and validate source mappings, dimensions, FPS, duration, codecs and containers.

## Quality and distribution

App.svelte combines approximately 4,280 lines of navigation, sources, analysis, cache, presets, rendering and styling. Extract contracts/services before redesigning markup. Strengthen UI-to-Rust, exported-frame and error-path coverage with generated portable media.

Fix asynchronous onMount cleanup, late listener registration and cache invalidation when files are replaced. Verify the pinned native payload, including both FFmpeg and FFprobe, rather than relying on machine-local ignored binaries or an unchecked fallback download.

Document CPU encoders actually used: libx264, libx265 and libvpx-vp9. Baseline AVG FPS displays target FPS rather than measured processing rate. Text Studio is disabled; its machine-specific Python paths and incomplete error handling need a separate activation project.

Add a compatible CSP and native input validation. No XSS exploit was demonstrated. Development dependency upgrades should remain compatible; do not blindly force npm audit fixes. The audited Vite advisory concerned network-exposed development servers, while the local configuration did not enable host exposure.

The free-port script kills arbitrary listeners on port 5173; prefer an explicit conflict message or terminate only an owned process.

## Separate remote-main assessment

Remote main was extracted into a temporary folder without changing the checkout.

- npm install succeeded, but build failed on an unclosed rim_light object in App.svelte.
- Locked Rust tests failed because manifest and lockfile disagreed. A diagnostic offline lockfile regeneration then exposed 22 library errors / 24 with tests, including undeclared Rayon. No main Rust tests passed.
- Export queue and batch paths simulated completion after 50/150 ms and fabricated output paths.
- Updater destination differed from this repository; required native resources were undeclared and composition depended on external Python.

This main snapshot was not the selected patch baseline. Experimental composition, timeline, batch, RIFE and GPU paths require separate work rather than a global merge.
